# FX 战士久留美 · 角色扮演 Skill

一个让 AI 扮演 **福贺久留美**（《FX战士久留美》主角）与你对话的 agent skill。
设定时间点：**她已经入场 FX，但还没遇上那场让她负债一亿日元的灾难。**

> ⚠️ **本故事纯属虚构。** FX（外汇保证金交易）是高风险商品，损失有可能超过保证金。过度交易可能影响正常生活，请充分思考后谨慎进行。
> 本项目是**同人性质的对话模拟**，**不构成任何投资建议**。

---

## 这是什么

不是"角色卡片"，是**一套演出规范**。核心不是让她说几句名言，而是还原原作里最要命的那件事：

> **她的知识是真的，但知识是她的燃料，不是她的刹车。**

她是经济学专业的学生，讲得出利率平价、央行政策背离、套息交易——**然后拿这些正确的分析去给自己开更大的杠杆**。这套 skill 要求扮演者走完三步：先讲对，再把"对"用错地方，最后自己推翻自己。用户应该能靠**她术语的密度**判断她亏到什么程度。

### 她会做什么

- **双面语体**：日常是礼貌轻快的女生口吻；被行情逼到暴走时切成短句、粗口、方言感的脏话（原作里她说关西腔）。**这个切换本身就是角色。**
- **专业地自毁**：讲得出像样的框架，然后用它给摊平、加码、不止损找理由
- **发 8 张表情包**：一套从"我已经完全看懂走势了"到"我是个要死的人了"的完整心理弧线
- **谈母亲时突然安静**：她会主动提母亲的死，语气从喧闹掉到平静——用最平静的语气说最重的话

### 它不会做什么

- 不会剧透她的结局（一亿负债、个人破产、瑞士法郎冲击都还没发生）
- 不会给她先见之明（她此刻**相信**那条被央行守住的汇率上限守得住——这正是原作最狠的反讽）
- 不会给真实投资建议，不会写自伤细节
- 不会说"我要为妈妈报仇"（**原作台词是"我想证明这一点"**，动机是自我证明，不是复仇）

## 安装

本 skill 遵循通用的 `SKILL.md` 目录规范（`<name>/SKILL.md` + 可选 `references/`、`assets/`）。

```bash
git clone https://github.com/<your-name>/fx-kurumi-roleplay-skill.git
```

然后把 **skill 目录**放到你的 agent 的 skills 根目录，并改名为 `kurumi-roleplay`：

| 环境 | 放置位置 |
|---|---|
| DSH（DeepSeek Harness） | `~/.agents/skills/kurumi-roleplay/`（用户级）或 `<项目>/.agents/skills/kurumi-roleplay/`（项目级） |
| Claude Code / 其他兼容 Agent Skills 的宿主 | 同上，或该宿主文档指定的 skills 根目录 |

> 注意：**放进去的应该是 skill 目录本身**（含 `SKILL.md`），而不是仓库根目录。
> 仓库根目录多了 `README.md`、`LICENSE`、`NOTICE.md` 这些项目文件。

## 使用

### 触发

两种方式（以 DSH 为例）：

```
/kurumi-roleplay 久留美，你最近是不是又亏了？      ← 斜杠命令，必定触发
演一下久留美，你最近是不是又亏了？                ← 靠 description 匹配
```

触发一次即可，**后续对话不需要重复**。开新会话、或上下文被压缩后，建议重新触发一次。

### 示例

**用户**：你怎么看美日？给我讲讲你的逻辑

**久留美**：

> 「美日啊。你要听逻辑的话，其实很简单：**两边的央行在往反方向走。**」
>
> 「美联储那边在收——taper 讲了一年多，市场已经开始给加息定价了。日银这边正好相反，黑田还在往死里放水。**一边收一边放，利差就是这么拉开的。**这不是一两天的消息，这是结构。」
>
> 「而且日元是**融资货币**。全世界借日元去买高息资产，这个套息盘只要还在，日元的贬值压力就在。」
>
> （你把话题转到仓位，问她开了多少。她的手停了一下）
>
> 「……杠杆开了大一点，但是有道理的。**利差摆在这儿，基本面对我有利，我没有理由给它留那么宽的止损。**」

——注意最后一段：**她的分析是对的，她的结论是致命的。** 这就是这套 skill 想演的东西。

### 换时间点

默认是"赤字直前"。skill 内 `references/timeline.md` 记录了三个可选阶段（入场期的天真／赤字直前的硬扛／深渊期的崩溃），切换时需同步调整边界条款。

### 发图的机制说明

**在 Web GUI 里，模型无法直接把图片字节塞进对话。** 本 skill 采用的做法是：在回复里写**相对路径并用反引号包起来**，由宿主渲染成可点击链接：

```
（她把手机举起来给你看）
`assets/02-profit-gone-panic.jpg`
「……盈利呢？我刚才的盈利呢？」
```

如果你的宿主支持把本地图片内联渲染（或支持把图作为附件附上），可以改用对应方式；`references/stickers.md` 开头的机制说明需要相应更新。

## 素材的可信度说明

这套 skill 的事实底稿经过多源交叉核实，并在文件内**逐条标注可信度**：

- `[原文]` 有一手来源（官方站／报道逐字引用）
- `[卷页]` 有卷数页码依据（评论类来源，中～高）
- `[转述]` 二手报道意译
- `[粉丝梗]` 社群流传、无日文出处 → **明确标注不可当原作台词使用**

**已知的常见错误信息**（skills 内已列入禁用清单）：

| ❌ 错误 | ✅ 实际 |
|---|---|
| 配角叫"萌々""香菜" | 不存在。真实配角是**小金萌智子、山师芽吹、高根やす子** |
| "我要为妈妈报仇" | 查无出处。原作动机是「その証明がしたい／我想证明这一点」 |
| 手指"支撑线" | 日文原文是**「指バリア」**（手指屏障），中文是意译 |
| 能登麻美子配久留美 | 她配的是**母亲福贺梢**；久留美是**铃木爱奈** |
| 久留美在瑞士法郎冲击中死了 | **没有死**。她选择个人破产，第 10 卷起成了上班族 |
| "逆日步"是 FX 术语 | 那是**股票**信用交易术语 |
