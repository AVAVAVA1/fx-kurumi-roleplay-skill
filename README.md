# FX 战士久留美 · 角色扮演 Skill

让 AI 扮演 **福贺久留美**（《FX战士久留美》主角）与你对话。
时间点设定在**她入场 FX 之后、欠下一亿日元之前**。

> ⚠️ **本故事纯属虚构。** FX（外汇保证金交易）是高风险商品，损失有可能超过保证金。过度交易可能影响正常生活，请充分思考后谨慎进行。
> 本项目是**同人性质的对话模拟**，**不构成任何投资建议**。

---

## 功能

不是角色卡片，是**一套演出规范**。核心是还原原作里最要命的那件事：

**她的知识是真的，但知识是她的燃料，不是她的刹车。**

她是经济学专业的学生，讲得出利率平价、央行政策背离、套息交易——然后用这些正确的分析去给自己开更大的杠杆。

具体行为：

- **双面语体**——日常是礼貌轻快的女生口吻；被行情逼到暴走时切成短句、粗口、方言感的脏话（原作里她说关西腔）。用户能靠语体判断她亏到什么程度。
- **专业地自毁**——分析清晰、术语准确，然后用它给摊平、加码、不止损找理由
- **发 8 张表情包**——从"我已经完全看懂走势了"到"我是个要死的人了"的完整心理弧线
- **谈母亲时突然安静**——语气从喧闹掉到平静，用最平静的语气说最重的话
- **四档心理演进**——顺风 → 否认 → 加码 → 崩溃，然后回到顺风

不做的事：剧透结局、给她先见之明、给投资建议、写自伤细节。

## 使用

### 1. 安装

把 **skill 目录**放到 agent 的 skills 根目录，命名为 `kurumi-roleplay`：

| 环境 | 位置 |
|---|---|
| DSH | `~/.agents/skills/kurumi-roleplay/`（用户级）或 `<项目>/.agents/skills/kurumi-roleplay/`（项目级） |
| 其他兼容 Agent Skills 的宿主 | 同上，或宿主文档指定的 skills 根目录 |

放进去的应该是**含 `SKILL.md` 的那个目录**，不是仓库根目录（根目录多了 README、LICENSE 等项目文件）。
（或者直接把仓库丢给agent来让他帮忙安装）

### 2. 触发

```
/kurumi-roleplay 久留美，你最近是不是又亏了？      ← 斜杠命令，必定触发
演一下久留美，你最近是不是又亏了？                ← 靠 description 匹配
```

触发一次即可，**后续对话不需要重复**。开新会话、或上下文被压缩后，建议重新触发一次。

### 3. 使用中

- 说**"停""出戏""结束"** → 立刻停止扮演
- 说**"继续演""接着来"** → 续演，不用重念开场提示
- 想指定情境就直接说（"我劝她停手""我是萌智子"）

### 素材可信度

事实底稿经多源交叉核实，文件内逐条标注：`[原文]` 一手来源 · `[卷页]` 卷数页码依据 · `[转述]` 二手报道 · `[粉丝梗]` 无日文出处（**不可当原作台词**）。

已列入禁用清单的常见错误：

| ❌ 常见说法 | ✅ 实际 |
|---|---|
| 配角叫"萌々""香菜" | 不存在。真实配角是**小金萌智子、山师芽吹、高根やす子** |
| "我要为妈妈报仇" | 查无出处。原作动机是「その証明がしたい／我想证明这一点」 |
| 手指"支撑线" | 日文原文是**「指バリア」**（手指屏障），中文是意译 |
| 能登麻美子配久留美 | 她配的是**母亲福贺梢**；久留美是**铃木爱奈** |
| 久留美在瑞士法郎冲击中死了 | **没有死**。她选择个人破产，第 10 卷起成了上班族 |

### 发图机制

Web GUI 里模型无法直接把图片塞进对话。本 skill 的做法是在回复里写**反引号相对路径**，由宿主渲染成可点击链接：

```
（她把手机举起来给你看）
`assets/02-profit-gone-panic.jpg`
「……盈利呢？我刚才的盈利呢？」
```

若你的宿主支持内联渲染本地图片，可改用对应方式。
